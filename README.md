# Project 2 packet

Every file you need for Project 2 is in this folder, in the order you use them. Do the steps in order on the course site: [Project 2, Step by Step](https://starlight-ai-101.vercel.app/projects/project-2/supplements/process-steps).

## Import it

1. Unzip the packet.
2. Drag the `project-02` folder into your Obsidian vault.
3. Open this file in Obsidian.

## Your files

| Step | File | What you do |
|---|---|---|
| 1 | `intent.md` | Map your process without AI. |
| 3 and 4 | `source-verification-log.md` | Log each source and check each claim. |
| 5 | `research-brief.md` | Answer your research question with checked claims. |
| 6 | `process-map.canvas` | Add one node per step. |
| 7 | `00-start-here.md` and `01-step.md` | Write the start file. Copy `01-step.md` for each step, up to five. |
| 8 | `ai-use-log.md` and `outputs/` | Log every run. Save the first run in `outputs/`. |
| 10 | `feedback.md` | Record peer critique. |
| 11 | `decision-note.md` | Name the gap, the fix, and why. |
| 12 | `diagram.md` and `disclosure.md` | Draw the workflow. State what the model did and what you decided. |

Replace every `[bracketed placeholder]` with your own words. Delete the italic guidance lines before you submit.

## Submit

Keep these file names while you work. When you submit, rename each file to `AI101_P2_[Last]_[First]_[Artifact].ext`. Rename inside Obsidian so your links update. Push the folder to the GitHub repository you share with the instructor.

## Privacy

Use only material you have permission to share. Do not put grades, finances, health information, or anyone else's personal information in this folder.
